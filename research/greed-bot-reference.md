## known issues & user complaints

1. **Slow commands** — most features reported as very slow
2. **Broken dashboard** — dashboard doesn't work (consistently reported)
3. **Automod issues** — automod feature called "useless" by reviewers
4. **Autorole unreliable** — doesn't always assign roles to new members
5. **Features not working** — "most no longer work" per top.gg review
6. **Premium docs incomplete** — full premium documentation unreleased

## strengths (what sonder must match or beat)

1. **Massive feature set** — ~1,000 commands covering every category
2. **Free core** — antinuke, antiraid, automod all free (unusual)
3. **AntiNuke/AntiRaid** — praised as "perfect for moderation needs"
4. **11 languages** — broad international support
5. **All-in-one positioning** — "basically an all in one" per users
6. **Community size** — 80k+ servers = network effects
7. **Scripting/variables** — flexible customization system

---

## weaknesses sonder can exploit

1. Speed — sub-200ms responses instantly differentiates
2. Dashboard — actually working dashboard is a competitive advantage
3. No AI features — zero intelligence layer
4. Reliability — "most features don't work" complaints
5. No proactive features — entirely reactive/command-based
6. No analytics — admins have no data about server health
7. Stale innovation — feature set is broad but not evolving
